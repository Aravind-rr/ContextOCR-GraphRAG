# Models and configuration

All settings come from environment variables. Important values are `OCR_ENGINE`, `CONFIDENCE_THRESHOLD`, `CANDIDATE_COUNT`, `PADDLE_LANG`, `EMBEDDING_MODEL`, `RETRIEVAL_TOP_K`, `CHUNK_SIZE`, `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`, `SLM_MODEL_PATH`, and `SLM_MAX_NEW_TOKENS`. Model paths are never hard-coded. Download models before an offline live review and verify readiness on the System Status page.
